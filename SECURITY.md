# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Car List API PHP SDK, please **do not** create a public GitHub issue.

Instead, report it privately by emailing:

**security@carlistapi.com**

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

We will acknowledge receipt of your report as quickly as possible and work with you to resolve the issue.

## Supported Versions

| Version | Supported |
|----------|-----------|
| 0.1.x | ✅ |

This SDK is currently pre-1.0. Security fixes are provided for the latest released version. Once a 1.0 release is tagged, this table will be updated to track supported major versions.
