# Contributing

Thank you for your interest in contributing to the Car List API PHP SDK!

We welcome bug reports, feature requests, documentation improvements, and pull requests.

---

## Reporting Issues

If you've found a bug, please create a GitHub Issue and include:

- SDK version
- PHP version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior

If applicable, include the full exception message and stack trace.

---

## Pull Requests

Before opening a pull request:

- Fork the repository
- Create a feature branch from `main`
- Write clear, descriptive commit messages
- Add or update tests where appropriate
- Update documentation when behavior changes

Please keep pull requests focused on a single improvement.

---

## Development

Install dependencies:

```bash
composer install
```

Run tests:

```bash
composer test
```

Run static analysis (if configured):

```bash
composer analyse
```

Run code style checks (if configured):

```bash
composer lint
```

---

## Coding Standards

This project follows:

- PSR-12 coding standards
- Semantic Versioning
- Backward compatibility whenever possible

---

## Questions

If you have questions before starting work, feel free to open a GitHub Discussion or Issue.
